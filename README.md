# ARISE GG GUN Bot policies

This repository folder contains draft Terms of Service and Privacy Policy documents for the ARISE GG GUN Discord bot.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `arise-gg-gun-policies`.
2. Upload `terms-of-service.md` and `privacy-policy.md`.
3. Open Settings → Pages.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for deployment and use the published site URL shown in Settings → Pages.
6. Add the two published page URLs to Discord Developer Portal → your bot → General Information.

Before publishing, replace the contact placeholders and make the privacy policy match what the bot actually collects and stores. GitHub repository file links are not the same as GitHub Pages website links.
